# Shellbit

Фронтенд для ретро-эмуляторов на Godot 4.6 (GDScript). Сейчас — **этап 1**: интерфейс, библиотека игр и запуск игр через ядра libretro.

## Как запустить

1. Открой Godot 4.6 → **Import** → выбери файл `project.godot` из этой папки.
2. Нажми **F5** (или ▶ в правом верхнем углу).
3. Нажми «+ Папка с играми» и выбери папку с ROM-файлами (.nes, .sfc, .md, .gba…).

Управление: стрелки / крестовина / стик — перемещение, **A / Enter** — выбрать, **B / Esc** — назад,
**Y / F** — избранное, **LB RB / Q E** — другая приставка, **X / Tab** на главном — пересканировать папки.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `autoload/Settings.gd` | Настройки (файл `user://settings.cfg`) |
| `autoload/Lang.gd` | Язык интерфейса, переводы из `data/i18n/strings.tsv`, числа со словами |
| `autoload/CoreManager.gd` | Список приставок из `data/systems.json` |
| `autoload/Library.gd` | Поиск игр, недавние, избранное (`user://library.json`) |
| `autoload/InputMapper.gd` | Свои действия ввода, определение типа геймпада, раскладка кнопок по приставкам |
| `autoload/UiTheme.gd` | Цвета, шрифты, стиль кнопок и рамки фокуса |
| `autoload/SceneRouter.gd` | Переходы между экранами, «Назад», всплывающие сообщения |
| `scenes/home/` | Главный экран |
| `scenes/library/` | Экран одной приставки |
| `scenes/components/` | Карточка игры, плитка приставки, строка подсказок, рисунок геймпада (`PadView.gd`) |
| `scenes/settings/` | Настройки и экран «Кнопки приставок» (`PadMapScreen`) |
| `data/pads.json` | Геймпады приставок: кнопки, их раскладка по умолчанию и как их рисовать |
| `scenes/player/` | Экран игры: картинка, звук, кнопки |
| `native/` | C++-модуль RetroCore (исходники + godot-cpp) |
| `addons/shellbit_core/` | Собранный модуль (.dll) и его описание для Godot |

`user://` в Windows — это `%APPDATA%\Godot\app_userdata\Shellbit`.

## Важно при экспорте в .exe

`data/systems.json`, указатели обложек `data/covers/*.txt`, справочники `data/meta/*.txt` и таблица переводов `data/i18n/strings.tsv` — не ресурсы Godot, поэтому в настройках экспорта
добавь их вручную: **Project → Export → Resources → Filters to export non-resource files** → впиши `data/*.json, data/covers/*.txt, data/meta/*.txt, data/i18n/*.tsv, *.ico`.
(`data/*.json` захватывает и `data/pads.json`, а `*.ico` — иконку окна `icon.ico`.)
Иконка самого .exe: **Project → Export → Windows → Application → Icon** → `res://icon.ico`.

## Этап 1: сборка C++-модуля (Windows, один раз)

1. **Visual Studio Build Tools 2022 или новее** (бесплатно): https://visualstudio.microsoft.com/downloads/ →
   «Build Tools for Visual Studio». В установщике отметь **«Разработка классических приложений на C++»**
   (Desktop development with C++). Справа проверь, что отмечены **MSVC**, **Windows SDK** и **C++ CMake tools for Windows**.
2. **Python 3**: https://www.python.org/downloads/ — при установке поставь галочку **«Add python.exe to PATH»**.
3. **Закрой Godot**, затем дважды щёлкни `native/build.bat`. При первом запуске он сам скачает библиотеку godot-cpp
   в `native/godot-cpp`, сборка идёт 5–15 минут. Временные файлы сборки лежат в `%LOCALAPPDATA%\Shellbit-build`.
4. В папке `addons/shellbit_core/bin/` появится `shellbit_core.windows.template_debug.x86_64.dll`.

## Ядра libretro

Ядро — это готовый эмулятор одной приставки. Скачай нужное с официального сервера:
https://buildbot.libretro.com/nightly/windows/x86_64/latest/ (например, `fceumm_libretro.dll.zip` для NES),
распакуй и положи `.dll` в папку ядер:

`%APPDATA%\Godot\app_userdata\Shellbit\cores`

(Её можно открыть кнопкой «Открыть папку ядер» на экране ошибки.) Какое ядро нужно какой приставке —
поле `default_core` в `data/systems.json`.

### PlayStation 1

- Ядро: **`pcsx_rearmed_libretro.dll`**. Работает и без BIOS (встроенная замена), но с настоящим BIOS
  совместимость выше: положи свой дамп `scph5501.bin` в `%APPDATA%\Godot\app_userdata\Shellbit\system`.
- Форматы игр: `.cue` (рядом с ним лежат `.bin`), `.chd`, `.pbp`, `.m3u`.
- Многодисковые игры: создай `Название (USA).m3u` — текстовый файл, где по строке перечислены `.cue` всех дисков.
  Shellbit покажет игру одной карточкой и запустит набор целиком.
- Сохранения внутри игры (карта памяти) лежат в `...\Shellbit\saves\<имя игры>.srm`.

## Управление в игре

| Геймпад | Клавиатура | RetroPad |
| --- | --- | --- |
| Крестовина / левый стик | Стрелки | Крестовина |
| A (нижняя) | Z | B |
| B (правая) | X | A |
| X (левая) | A | Y |
| Y (верхняя) | S | X |
| LB / RB | Q / W | L / R |
| Start / Back | Enter / Shift | Start / Select |
| **Правый стик (нажать)** или **View + Menu** | **Esc** | Меню паузы |
| **Share** (Xbox Series, PS5) или «Скриншот» в меню паузы | **F12** | Скриншот → `Изображения\Shellbit` |

Это раскладка **по положению**: нижняя кнопка геймпада Xbox — нижняя кнопка
приставки (B у SNES), правая — правая (A у SNES).

### Своя раскладка для каждой приставки

**Настройки → Управление → Кнопки приставок.** Слева — кнопки приставки,
справа — рисунок её геймпада и вашего (Xbox или PlayStation): на кнопках вашего
геймпада написано, какая кнопка приставки на них стоит. LB / RB — другая приставка.

- **A** на строке → «Нажмите кнопку…» → нажмите кнопку геймпада. Через 5 секунд или по Esc — отмена.
- **◀ ▶** — перебрать кнопки геймпада по списку.
- Если кнопка геймпада уже занята, две кнопки приставки **меняются местами**.
- У NES, SNES и Game Boy есть готовая раскладка **по надписям**: A на A, B на B.

Раскладки хранятся в `user://settings.cfg`, раздел `[pads]` — только то, что вы поменяли.
Клавиатура и крестовина не переназначаются; правый стик — всегда меню паузы.

### Ускорение и перемотка назад

| Что | Геймпад (по умолчанию) | Клавиатура |
| --- | --- | --- |
| Перемотка назад (держать) | LT | Backspace |
| Ускорение (держать или нажать — см. настройки) | RT | Пробел |

У PlayStation и Nintendo 64 курки нужны самой игре, поэтому там кнопки
геймпада для перемотки и ускорения не назначены — выберите их в «Кнопках приставок».
Скорость (×2…×8), режим кнопки и длина перемотки — **Настройки → Игра**.

Как это устроено (`scenes/player/Player.gd`, раздел «Ускорение и перемотка»):
- **ускорение** — за один кадр экрана просчитывается несколько кадров приставки;
- **перемотка** — каждые 2 кадра игра делает быстрое сохранение (`save_state`)
  на «ленту»; пока кнопка зажата, снимки загружаются с конца ленты.
  Лента занимает не больше `Settings.REWIND_BUDGET_MB` (256 МБ): у тяжёлых
  приставок снимки делаются реже.

Какие кнопки у каждой приставки и как они нарисованы, описано в `data/pads.json`
(подсказка по полям — в начале файла). Там же можно поправить раскладку по умолчанию.

## Сохранения

- **Меню паузы:** продолжить, начать заново, 3 слота сохранений, выйти в библиотеку.
- На слоте: **A** — загрузить (в пустой — сохранить), **X** — сохранить сюда.
- При выходе игра **сохраняется сама**, а при следующем запуске продолжается с того же места.
- Файлы лежат в `%APPDATA%\Godot\app_userdata\Shellbit\states\` — своя папка для каждого файла игры.

## Обложки

Обложки скачиваются сами из бесплатного архива [libretro-thumbnails](https://github.com/libretro-thumbnails)
(сначала с thumbnails.libretro.com, при ошибке — с GitHub) и хранятся в `%APPDATA%\Godot\app_userdata\Shellbit\covers\`.
Указатели `data/covers/<приставка>.txt` («ключ игры → имя обложки») собраны заранее из этого архива.
Если игры нет в архиве, на карточке остаётся название текстом.

**Свои обложки** (важнее скачанных):
- положи картинку с тем же именем рядом с игрой: `Adventures of Donald Duck.gb` → `Adventures of Donald Duck.png`
  (подходят `.png`, `.jpg`, `.jpeg`, `.webp`);
- или на экране приставки нажми **Start / Menu** (F1) → «Выбрать свою обложку…». Там же — «Убрать свою обложку».

## Страница игры

В библиотеке **A** открывает страницу игры: обложка, год, жанр, число игроков, разработчик
(из открытой базы [libretro-database](https://github.com/libretro/libretro-database), собраны в `data/meta/`),
время в игре и сохранения. Отсюда можно запустить игру с места выхода или с любого слота.

## Описание игры

Описание пишется в текстовом файле **рядом с игрой, с тем же именем** и расширением `.txt`
(кодировка UTF-8): `Battletoads (U) [!].nes` → `Battletoads (U) [!].txt`.
Если у игры несколько версий, файл достаточно положить рядом с любой из них.

В одном файле можно держать текст на нескольких языках:

```
[ru]
title: Боевые жабы
Три жабы-космонавта летят спасать подругу Энджику и принцессу
из плена Тёмной королевы.

Знаменита своей сложностью — особенно уровень с гонками на байках.

[en]
Three space toads set out to rescue their friend from the Dark Queen.

[ja]
title: バトルトード
宇宙のカエル3匹が、ダーククイーンから仲間を救い出す。
```

- `[ru]`, `[en]`, `[zh]`, `[ja]`, `[de]`, `[fr]`, `[es]`, `[pt]`, `[ko]` — с этой строки начинается текст на этом языке.
- `title:` (или `название:`) — необязательная первая строка раздела: название игры на этом языке.
  Показывается на странице игры вместо названия из имени файла.
- Всё остальное — описание. Пустые строки (абзацы) сохраняются.
- Какое описание показать: **язык интерфейса → английский → русский → текст без метки**.
  Например, если японского раздела нет, японец увидит английский текст.
- Название (`title:`) берётся только на языке интерфейса или английское; если его нет —
  показывается название из имени файла.
- **Старые файлы без меток** продолжают работать: весь текст считается описанием для любого языка.

Разбирает файл функция `GameInfo.parse_description()` в `scripts/GameInfo.gd`.

## Языки интерфейса

Языки: русский, английский, китайский (упрощённый), японский, немецкий, французский,
испанский, португальский (Бразилия) и корейский.
Язык меняется в **Настройки → Язык**: A на строке «Язык интерфейса» открывает список. «Как в системе» — язык Windows.

- Все переводы — в таблице `data/i18n/strings.tsv` (столбцы `ru  en  zh  ja  de  fr  es  pt  ko`, разделитель — табуляция).
  Её удобно править в LibreOffice Calc или Excel: открыть как «текст с разделителями-табуляциями»,
  сохранить в том же формате и в кодировке UTF-8.
- Первый столбец — русский текст, он же ключ: в коде пишется `tr("Настройки")`.
  Новый текст в коде → добавить строку в таблицу.
- `\n` в таблице — перенос строки. `|` разделяет формы слова для чисел: `%d игра|%d игры|%d игр`
  (в европейских языках две формы, в китайском, японском и корейском — одна).
  Правила, какую форму брать, — в `Lang._plural_index()`.
- Новый язык: добавить столбец в таблицу, код языка — в `Lang.SUPPORTED` и `Lang.CHOICES`,
  при необходимости — шрифт в `UiTheme.FONTS` и правило чисел в `Lang._plural_index()`.
- Для китайского, японского и корейского Shellbit сам берёт шрифты Windows (Microsoft YaHei, Yu Gothic, Malgun Gothic).
